# Ciranda Criança Site Acadêmico
## 📖 Sobre o projeto

Este projeto simula o site de uma escola infantil, com visual colorido e acolhedor. Ele foi criado para colocar em prática a estrutura de páginas com HTML e a estilização com CSS.

## 💡 Inspiração

Me inspirei no universo de escolas de pré-escola e fundamental 1: cores vivas, formas arredondadas e um clima leve e divertido, pensado para agradar tanto as crianças quanto os pais.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 📂 Estrutura do projeto

```
escola-alegria-site/
├── index.html
├── css/
│   └── style.css
└── ciranda logo.png/
```

## ▶️ Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/butjuaozin/Site-Academico.git
   ```
2. Abra a pasta do projeto.
3. Dê dois cliques no arquivo `index.html` para abrir no navegador.

## ✨ O que aprendi

- Estruturar páginas com HTML semântico
- Estilizar com CSS (cores, fontes, espaçamentos)
- Organizar arquivos de um projeto
